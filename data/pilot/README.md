# Pilot recording folder

Save 2 or 3 real breathing WAV clips here for M4. There are no recordings in this folder yet.

Use the app's Record audio mode, stop the recording, and select Save original WAV. Move the downloaded file here and rename each take, for example P1_take1.wav or P2_take1.wav. These names are suggestions for future files, not existing recordings.

Aim for about 60 seconds of comfortable breathing in a quiet room. The supported duration is 30 to 120 seconds. Keep the chosen microphone position steady and note the device, approximate distance, and conditions. Save each take before recording another one.

Follow [the M4 pilot guide](../../docs/10_M4_PILOT_GUIDE.md) and fill [the worksheet](../../docs/11_M4_PILOT_WORKSHEET.md). Count full breathing cycles or mark the same event once per cycle over the app's actual analyzed interval. Do not use detected markers as manual reference labels.

The .cache folder contains generated engineering fixtures from earlier stages. Those are separate from this real-recording pilot.
